# Aplikasi Antrean Klinik Mandiri
Aplikasi ini dirancang untuk mengoptimalkan antrean loket klinik secara real-time.

### Fitur Utama:
- Manajemen antrean berbasis nomor urut otomatis.
- Dasbor pemantauan status panggilan untuk kasir/dokter.
- Arsitektur clean code dengan optimasi query MySQL.

*Catatan: Sistem ini dibangun menggunakan kombinasi logika mandiri dan ketangkasan adaptasi AI untuk efisiensi penulisan kode.*
